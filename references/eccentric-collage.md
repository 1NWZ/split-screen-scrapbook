# 分界与古怪拼贴

## 分界要有物理结构

- 图1：密集双线活页环，两张纸各自有黑色穿孔；金属环跨过接缝进入孔洞，环有前后关系，纸边有厚度与压影。可取9–11环，具体数量服从画幅，环不能只是浮在横线上。
- 图2：真正的扇贝纸边/蕾丝和钻点沿边，下层照片被不规则边缘部分盖住；不是在直切线上画一根正弦曲线。与金属装订属于两个可选方向，避免无理由同时叠三种分界。
- 图3：较疏的金属活页与可见锁扣/脊条，6–7个有体积的环、铆钉/孔洞、反射与接触阴影。允许轻微斜角，避免均匀渐变描边的矢量椭圆。
- 占全幅高约6%–10%，上下都要有视觉穿入；人物五官安全区不可被环、纸边或跨屏材料侵入。跨屏可出现在袖口和背景，不能把整张脸盖住。

## 蕾丝要能指出具体来源形态

|库|必须保留的识别特征|可用方式|
|---|---|---|
|13|旧纱矩形、松散毛须、半透明密网|倾斜碎布压在标题字头下，安全别针/回形针固定一个角；去除原图现成文字|
|14|心形轮廓、扇贝织边、内层细网|不规则小贴片；可嵌入照片里杯子、帽子或眼镜的物件裁片，避免再加一张完整人像|
|15|星芒放射、卷草、细线网结、异形徽章|主装饰节点；用户要更古怪时可以保留飞马作为超现实剪贴物，不应只转换成看不清的背景压纹|

普通版轮换使用一至两种；明确要求展示整个蕾丝库时可以三种都用，但尺寸分大中小，不能三块等大平铺。主贴片约18%–28%画布宽，辅贴片约10%–18%。同张图可有金属、蕾丝、纸条、少量宝石，这些材质围绕一个标题组织。

## 如何更小众，而不是只增加数量

- 不对称：标题偏轴或轻倾斜3°–7°；字头与布角叠压，保留字形可读。左右不做镜像。
- 尺度错位：一个较大的异形蕾丝徽章，配少量微小单词纸条；局部紧密，旁边留出粉纸呼吸区。
- 物件呼应：照片中的咖啡杯可转成一张小黑白复印剪影，装入心形蕾丝。不是随意添加和照片无关的第二个人像。
- 材料冲突：旧奶白纱＋冷银钻链＋荧光小胶片；荧光只做局部点缀，不把全部文字改成荧光大色块。
- 路径：一根细珠链或白线串起2–3个节点，不要画满网络；1–2枚回形针/订书钉提供固定关系。
- 文案：主标题仍一个，另有1–3个短词。可以有诗意新文案，不抄素材原句，不把随手贴纸上的艺名当作用户姓名。

## 局部迭代

用户已认可照片时，固定其上屏像素、曝光和颜色，只生成可编辑的分界/底屏。若工具只能生成整图，可以在生成后用 `scripts/merge_edit.py` 恢复顶部原像素；渐变接缝必须落在脸部保护区之外。新旧图先对齐尺寸，不能拉伸原照片。

最终检查：能指出至少一个库中蕾丝的形态；装订穿孔和跨屏关系可见；标题可读；有2–3个大小不同的装饰节点；主色底仍占多数。不能用“古怪小众”几个词代替这些具体证据。
