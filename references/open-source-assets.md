# 开源原创素材库

公开版每次制作前实际查看 `assets/library/` 的十张母版。它们提供可分发的装订、材质字和蕾丝依据。宝石、珍珠和星星不使用原创替代母版，直接查看版权方授权公开分发的 `assets/references/05-elements.png`、`06-elements.png`、`07-elements.jpg`。不要把任何母版或参考图整张贴入成片；选择局部结构作为材质或重制依据。

## 文件与用途

- `original-dividers.png`：从四个象限选择一种分界。金属装订需保留孔洞、厚度、反光和投影；扇贝纸边用于柔和方案；跨界花体线用于图4式版式。
- `type-rhinestone-glow.png`：稀疏银钻长花体，字宽约画布58%，字高约28%。
- `type-pearl-chain-echo.png`：极细珠链花体，大量织物留白。
- `type-crochet-after.png`：细红线钩织手写体，落在深靛蓝牛仔布上。
- `type-multigem-soft-signal.png`：小颗粒彩宝双行花体，控制三种主色与少量透明钻。
- `type-crystal-blue-hour.png`：黑底双行银钻花体，长尾和疏密变化明显。
- `lace-rectangle-star.png`：右下小矩形网纱贴片，约画布宽24%。
- `lace-heart-bow.png`：左下心形扇贝贴片，约画布宽28%。
- `lace-crescent-orbit.png`：右上弯月星轨网结徽章，约画布宽30%。
- `lace-winged-pony.png`：右下带翅小马网结徽章，约画布宽28%；这是小马蕾丝题材的正式候选，应与其他三款蕾丝一起进入受控随机选择。用户点名小马时优先选用。

材质字标题内容必须按用户照片另写，不能机械复制母版示例词。蕾丝每张成片只选一个，在下屏留白区受控随机摆放；三张母版的位置只是候选示范，不固定角落。蕾丝不得放大到占据下屏主体，通常控制在成片画布宽18%–28%，复杂星轨形最多30%。

## 使用顺序

1. 先按照片颜色和构图选择下屏版式。
2. 查看十张公开母版与原始图5–7，选择一个分界、一个标题材料家族和2–3组点缀材料节点。
3. 蕾丝只选一个形态，并与主标题错开，避免固定右下角。
4. 若直接裁切母版中的元素，先清除母版背景并检查边缘；无法干净分离时，按该元素重制透明PNG，不携带整块背景。
5. 成片验收时确认素材家族可辨认，同时仍以用户照片和单一主色底屏为视觉主体。

## 变化规则

同一素材可以缩放、旋转、镜像、轻微改色或重新排列，但不能连续生成完全相同的组合。变化至少涉及版式、分界、标题材料、蕾丝形态或蕾丝位置中的三项。保持共同的扫描纸张、复古偏色、局部柔光过曝和实体材质语言。
