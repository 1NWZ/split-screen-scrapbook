# 混合制作流程

## 首选路线：人像像素锁定，模型负责材料

用户上传照片 → 人工/视觉模型分析与配方 → 原照片裁切/调色 → AI非人脸素材 → 代码精确布局 → 分层纠错 → 最终扫描质感。

禁止先让模型生成全幅人像再声称“完全保留五官”。原照片合成可保持五官几何结构，仍需检查裁切和滤镜是否破坏辨识。若用户允许改变姿势/服装才采用人像编辑模型；记录此选择。

### 1. 设计配方与代码

`scripts/compose.py --photo input.jpg --recipe recipe.json --out result.png`

依赖为 Pillow、NumPy，安装见 README。配方示例见 `recipe.example.json`。坐标均归一化；`crop` 和 `faces` 相对**原图经EXIF纠正后的尺寸**，`title_box` 与图层位置相对最终整张画布。每张脸都要登记。工具不自带人脸检测，不能把默认空列表当作保护成功。

代码保留原始裁切比例，按目标屏幕再作居中 cover 裁切。任何脸框被二次裁掉则报错，需调整 `crop`、上下比例或改图。群像必须全部容纳，必要时让照片区更宽松，不能牺牲边缘人物。

合成器提供轻复古滤镜、纯色纸面、基础星钻、波浪和金属环，以及精确文本与透明PNG叠层。基础元素仅用于底稿；与参考精度有关的真实蕾丝、布贴、复杂宝石和书法材质字应由资产层补足。

### 2. 非人脸资产提示词

附选定的原参考图；每次只生成需要的资产。以下模板用当前配方的具体内容替换，不能把花括号原样发送。

**材质标题**：
> 制作一个可单独合成的英文材质字资产。准确文字为“{title}”，共{词数}词，不添加任何其他字母。参照所附图{8/9/10/11/12}的连笔书法骨架、长尾、材料尺度与接触阴影，但使用当前指定的新文字。材料是{银色圆钻/小珍珠链/红线钩织/彩色宝石}。标题横向占据画面中央，周围留足透明边距，透明背景。材料边缘清晰真实，大小与间距有手工轻微不均匀。无人物，无背景纸，无水印。

**右下角单个蕾丝贴片**：
> 参考图{13/14/15}的米白细线织物、微小网孔、细密织网和干净收边，生成一个独立蕾丝贴片，形态从矩形织片、心形扇贝、异形星芒网结中只选一种；无毛边、毛须、散线或破损，不生成边条或多件拼盘，完整不裁切，透明背景，正面平铺，柔和浅接触阴影，不添加参考图的文字或额外主体。不要用实心波浪假装蕾丝。

**装饰贴片**：
> 参照图{5/6/7}中的{单一物件}，生成一个独立{颜色}实体贴片：{切面与表面描述}，正面略带自然角度，细暗边，左上小高光，右下极浅阴影，透明背景，不含人物/文字/背景格纹，不生成整张素材拼盘。

**底纸（可选）**：
> 正面平扫的{颜色及色值}单色复古纸，微弱纤维、轻微褪色、局部极浅{卷草}压纹，主色保持均匀，无主体，无文字，无边框，无大花纹。用于约{尺寸}纯色屏。

保存素材后实际检查透明通道。有些模型返回棋盘格图案而非透明背景，不能直接叠放。参照图不包含用户照片时，无须上传用户人像去制作宝石。模型支持情况由宿主实际工具决定，本 Skill 不绑定模型版本或 API。

### 3. 合成与字形

- 整块AI文字底板可用 `paper_panel` 指定图片、`panel_has_title: true` 关闭普通标题；只放入纯色屏。先按该屏宽高生成匹配比例，检查边缘是否有延展条纹或裁字。此模式不是透明贴片。

- 材质标题PNG：在配方 `layers` 中添加 `role: title`，合成器自动关闭普通主标题。把 `box` 设成标题包围盒，透明图像等比 contain 放入其中。不能用拉伸修复错误字形。
- 可安装字体：指定本地 `font` 路径；字体用于准确排普通文字或作为生成字形参考。未提供字体时使用 Pillow 默认字，只算基础预览；代码不附赠或伪造商业花体字体。
- 其他PNG层：`role` 可为 `decoration`，画布坐标box指定位置。所有叠层与正文均检查脸部保护区，默认拒绝交叠；不要通过关闭检查解决遮脸问题。
- 仅有的蕾丝贴片放下屏右下角，照片在上时可用 `box: [0.72,0.76,0.97,0.97]`；照片在下时也固定在下屏右下角，但需避开人物和五官，必要时缩小。禁止顶部或分界蕾丝。底纸材质层放纯色屏内，需排在标题之前；它仍以 `decoration` 输入，控制alpha，不应变成照片背景。
- 图层从列表前到后绘制；后面的在上。脚本会保存同名 `.recipe.json`，记录实际参数、输入SHA256与输出尺寸。保留原始照片和素材；PNG导出不嵌入原图EXIF。

### 4. 限制与完成标准

程序种子只控制本地噪声、基础元素与默认位置，不能保证外部模型逐像素复现。AI标题有错字时优先重新生成标题，或用已核验字体制作字形后指导编辑；不要多次重生成整个人像。局部修正最多连续尝试两次仍有问题时，交代具体缺失，不能把失败基础稿称为精准还原。

用户只修改分界/底屏时，可用 `scripts/merge_edit.py --original approved.png --edited ai-edit.png --out final.png --lock-top .49 --blend .02` 锁住已认可的上屏。参数为全幅高度比例：顶部49%逐像素保留，随后2%混合；先确认混合带在五官下方、装订上方，不能机械照抄参数。脚本检查新旧宽高比并记录像素一致性。上屏若要再次改调色，先完成并确认新的照片版本，再锁定。

宿主工具限制参考图数量时，选一张分界图与当前需要的蕾丝图，明确输入编号。一次改图中“当前成片＋图3＋从图13–15中选中的一张”已经足够，不能为了凑全部参考图省略当前编辑目标。
